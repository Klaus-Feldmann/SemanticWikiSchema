# Semantic WikiSchema (SWS) 0.5.02

SWS stores structured metadata and research data outside article text. Schemas define fields; authors edit entities through the **Data** tab. Reusable definitions and stable identifiers support shared maintenance and direct data queries.

Features include multilingual labels, configured Wikidata/local Wikibase sources, field notes, categories and namespace-scoped page suggestions. Authors can maintain their own values alongside source data. Optional SMW annotations, RDF/JSON exports and a Graph Explorer complement local data management.

**[Features, complete settings and requirements](docs/reference/SWS-0.5.02.en.md)** · **[Install SWS](docs/operations/install/README.md)** · **[Deutsch](README.de.md)**

We recommend connecting the existing MediaWiki to an AI through MCP before configuring SWS. The reference explains assistance with installation, use and schema design.

Qualified environment: MediaWiki 1.47.0-wmf.24, PHP 8.3.36, legacy parser and Vector 2022. Additional services/extensions depend on the selected features.
