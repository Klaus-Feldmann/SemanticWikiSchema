# Contributing to SemanticWikiSchema

Use a focused branch and describe a concrete research workflow, the change and the verification. Separate SWS code, the optional SMW wiki pages and the MCP-server patch. Preserve own/source identities, existing author credits and third-party licenses. Never commit credentials, local wiki settings, research corpora, dependency directories or deployment backups.

This test branch is based on SWS 0.1.0. Do not replace it with current upstream master without reviewing the intervening changes. Proposals to the original SWS project should follow Professional Wiki's request for one feature per issue or focused pull request. Publishing a fork does not submit those changes automatically.

See [verification](publication/VERIFICATION.md) for local checks. The original contributor/tooling files remain available, but production publishing workflows copied from upstream are archived under publication/upstream-workflows and are not active here.
