# Optional Wikidata registration

The helper registers a Wikidata Q-ID as `unlinkedwikibase_id` on the parsed page. SchemaBaseBridge uses that association for Wikidata-bound fields. It requires UnlinkedWikibase; existing page-to-source registrations can be used without this helper. No Wikidata or local Wikibase edits are made.

[LocalSettings setup](../../docs/operations/install/integrations.md#optional-wikidata-registration-helper) · [Deutsch](README.de.md)

## Invocation

```wikitext
{{#aewiwikidata:Q-ID|Wikipedia title|automatic (1/0)|missing-link category}}
```

A supplied Q-ID is validated. With no Q-ID and automatic resolution enabled, the title is resolved through the German Wikipedia sitelink; without an explicit title the current prefixed page title is used. A Wikipedia title alone counts as an explicit invocation for namespace eligibility. Resolution is not a universal identity matcher. A conflicting second Q-ID on the same parse is refused. Keep the UnlinkedWikibase job/cache workflow running and verify the registered association.

The bundled [minimal template](Vorlage-SemanticWikiSchema-Wikidata.wikitext) can be imported as `Template:SemanticWikiSchema/Wikidata`, then invoked on the corresponding page as `{{SemanticWikiSchema/Wikidata|Q=Q2063917}}`. Alternatively call the parser function directly. Do not put one fixed person's Q-ID into a shared person schema for all pages.

## Helper settings

Set overrides before the require_once include. These are optional helper variables, not registered SWS settings.

| Variable | Default | Meaning |
|---|---|---|
| `$wgAewiWikidataExplicitNamespaces` | `null` | Explicit Q-ID/title calls allowed in non-special namespaces, except redirects; an array restricts namespaces. |
| `$wgAewiWikidataAutoNamespaces` | `[ NS_MAIN ]` | Namespaces for automatic current-title resolution; `null` removes this namespace restriction. |
| `$wgAewiWikidataSmwProperty` | `'Wikidata-ID'` | Additional SMW property for the registered Q-ID; `''` disables it. Set `''` when SMW is not installed. Retain an intentionally configured existing property name/datatype. |

The optional ID annotation is separate from the source fields and ranked description generated by SWS. The companion magic-word PHP file is loaded automatically. Load exactly one helper copy; require_once does not prevent redeclaration if two different paths contain copies of the same global functions.
